# MoaView PRD

## Product Definition

MoaView는 웹툰/웹소설을 어디서 가장 싸고 편하게 볼 수 있는지 빠르게 찾게 해주는 통합 탐색 서비스입니다.

## MVP Goal

사용자가:

1. 작품을 검색하고
2. 플랫폼별 무료 회차, 가격, 이벤트, 쿠폰 조건을 비교하고
3. 가장 유리한 플랫폼으로 이동하도록 만든다.

## Target Users

### Primary Persona
여러 플랫폼을 함께 사용하는 웹툰/웹소설 소비자.

니즈:
- 통합 검색
- 무료 여부 확인
- 기다무 여부 확인
- 최저가 확인
- 쿠폰/이벤트 조건 확인

## MVP Scope

포함:
- 로그인
- 통합 검색
- 작품 상세
- 플랫폼 비교
- 쿠폰 적용 예상가 비교
- 찜
- 이메일 알림 이벤트
- 플랫폼 클릭 추적
- Mock crawler

제외:
- 플랫폼 로그인 연동
- 자체 뷰어
- OCR
- AI 추천
- 커뮤니티
- 리뷰/댓글
- 자체 결제
- 실제 production scraping

## Price Comparison Rules

가격 비교는 다음 항목을 분리해서 보여준다.

- 기본가
- 자동 즉시 할인가
- 쿠폰 다운로드 시 예상가
- 캐시백 포함 체감가

쿠폰 가격은 사용자가 직접 쿠폰을 다운로드해야 하는 경우 “확정 최저가”가 아니라 “쿠폰 적용 예상가”로 표시한다.

## Initial Platforms

- 네이버웹툰
- 카카오페이지
- 리디

## Initial Data Strategy

초기에는 실제 크롤링 없이 인기작 fixture 데이터를 사용한다.

초기 목표:
- 웹툰 인기작 50개
- 웹소설 인기작 50개
- 총 100개 작품

## Success Metrics

- 검색→상세 진입률
- 상세→플랫폼 클릭률
- 찜 등록률
- 쿠폰 CTA 클릭률
- 7일 재방문율
